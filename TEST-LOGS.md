# Логи тестов без копирования из Terminal

Диагностические и установочные `.command` теперь используют общий `server/logged_run.py`: весь stdout и stderr записывается в отдельный файл и одновременно остаётся виден в Terminal.

В начале печатается путь `Session log: ...`. В конце записывается JSON со статусом завершения, кодом выхода, временем, точной командой и путём к выводу. При ненулевом коде сохраняется и traceback. SIGINT передаётся дочернему тесту, чтобы его finally мог восстановить рабочий демон.

После запуска достаточно написать **«тест завершён»**, **«готово»** или **«завершился с ошибкой»**. Агент читает файлы самостоятельно:

- `logs/latest-test.json` — последний завершившийся или запущенный диагностический/установочный процесс.
- `logs/latest-native-reuse.json` — последний native reuse тест; поле command позволяет отличить dry-run от вычислений.
- `logs/sessions/*.json` и `*.log` — история отдельных запусков.

Статусы: `starting`, `running`, `completed`, `failed`. `completed` означает код выхода 0 у команды, а не автоматическое подтверждение качества экспериментального алгоритма: для него дополнительно читается JSON результатов.

Логирование включено для test-native-reuse, test-gpu-fa, test-16k, check-api, check-kv-cache, check-indexed-cache и установщиков enable-q8, enable-16k, enable-indexed-cache. Короткая команда `test-shift-active.command` использует тот же логируемый native reuse тест. Интерактивный OpenCode и личные переписки автоматически не записываются этим механизмом.

Проверены UTF-8, совместное сохранение stdout/stderr, сохранение ненулевого кода выхода и выполнение cleanup дочернего процесса при прерывании. История логов автоматически не очищается этой обёрткой.
